# Feedback & States

Componentes para comunicar estado al usuario: notificaciones, carga, vacío y progreso.

---

## Toasts

Notificaciones temporales que aparecen en la parte superior de la pantalla. Hay tres variantes:

| Clase | Uso |
|-------|-----|
| `.toast.toast-success` | Confirmación de acción exitosa |
| `.toast.toast-error` | Error — no auto-desaparece |
| `.toast.toast-info` | Información neutra, puede tener acción |
| `.toast.toast-warning` | Advertencia |

```html
<!-- Toast de éxito -->
<div class="toast toast-success">
  <div class="toast-icon"><!-- SVG check --></div>
  <span class="toast-text">Pago registrado exitosamente</span>
  <div class="toast-progress"></div>
</div>

<!-- Toast con acción -->
<div class="toast toast-info">
  <div class="toast-icon"><!-- SVG info --></div>
  <span class="toast-text">Nueva actualización disponible</span>
  <button class="toast-action">Actualizar</button>
  <div class="toast-progress"></div>
</div>
```

> `.toast-progress` es una barra animada que indica el tiempo restante antes del auto-dismiss. Omitir en `.toast-error`.

Para uso en React, usar el componente `<ToastContainer>` de `src/components/ui/Toast.jsx` que gestiona la cola de toasts via Zustand.

## Empty States

Para pantallas o secciones sin datos. Siempre incluir un CTA cuando sea posible.

```html
<div class="empty-state">
  <div class="empty-state-icon">💸</div>
  <div class="empty-state-title">Sin pagos este mes</div>
  <div class="empty-state-sub">Registra tu primer pago para ver tu resumen.</div>
  <button class="btn btn-primary" style="margin-top: 16px">Registrar pago</button>
</div>
```

## Skeleton Loaders

Usar durante la carga de datos. La clase `.skel` aplica la animación shimmer; el tamaño se controla con estilos inline.

```html
<!-- Card skeleton -->
<div class="skel" style="height: 120px; border-radius: var(--r-2xl)"></div>

<!-- Row skeleton (icono + líneas) -->
<div style="display: flex; gap: 12px; align-items: center">
  <div class="skel" style="width: 38px; height: 38px; border-radius: 50%"></div>
  <div style="flex: 1; display: flex; flex-direction: column; gap: 6px">
    <div class="skel" style="height: 14px; width: 60%; border-radius: 6px"></div>
    <div class="skel" style="height: 12px; width: 40%; border-radius: 6px"></div>
  </div>
</div>
```

## Badges

Etiquetas compactas para categorizar o etiquetar. El color comunica la categoría financiera.

| Clase | Color | Uso |
|-------|-------|-----|
| `.badge` | Neutro | Categorías generales |
| `.badge-income` | Verde | Ingresos |
| `.badge-deduct` | Rojo | Gastos |
| `.badge-reserve` | Naranja | Reservas |
| `.badge-volt` | Volt (#BDF300) | Novedades, destacado |

```html
<span class="badge badge-income">Ingreso</span>
<span class="badge badge-deduct">Gasto</span>
<span class="badge badge-volt">Nuevo</span>
```

## Progress Bar

Indicador de progreso lineal.

```html
<div class="prog-track">
  <div class="prog-bar" style="width: 65%"></div>
</div>
```

El ancho de `.prog-bar` controla el progreso (0%–100%).
