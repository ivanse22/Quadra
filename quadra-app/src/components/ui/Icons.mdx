# Icons

Librería de iconos SVG inline de Quadra. Todos los iconos están en `src/components/ui/Icons.jsx` como componentes React individuales.

---

## Uso en React

```jsx
import { IconArrowLeft, IconCheck, IconDollar } from '@/components/ui/Icons';

// Tamaño por defecto (16px)
<IconCheck />

// Con color personalizado
<IconDollar style={{ color: 'var(--fin-income)' }} />
```

La mayoría de iconos aceptan `size` y heredan el color de `currentColor`, por lo que responden a `color` en CSS.
