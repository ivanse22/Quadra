# AmountField

Campo de entrada de montos con numpad integrado. Diseñado específicamente para la entrada de valores monetarios en COP en contexto móvil.

---

## Características

- **Numpad táctil** que aparece al tocar el campo
- **Fuente dinámica** que se reduce automáticamente con valores largos (`clamp`)
- **Feedback táctil** via `navigator.vibrate(30ms)` en dispositivos compatibles
- **Soporte de teclado físico** — captura teclas numéricas y Backspace globalmente
- **Formato local** — usa `toLocaleString('es-CO')` para separadores de miles
- **Límite** de 9 dígitos
- **Hint condicional** de "Calculando tu disponible..." cuando `showCalculatingHint=true` y el monto ≥ 10,000

---

## Props

| Prop | Tipo | Por defecto | Descripción |
|------|------|-------------|-------------|
| `onChange` | `(value: number) => void` | — | Callback con el valor numérico en cada keystroke |
| `showCalculatingHint` | `boolean` | `false` | Muestra el hint verde cuando el monto es ≥ 10,000 |

---

## Uso

```jsx
import AmountField from '@/components/ui/AmountField';

function RegistrarPago() {
  const [monto, setMonto] = useState(0);

  return (
    <AmountField
      onChange={setMonto}
      showCalculatingHint={true}
    />
  );
}
```
